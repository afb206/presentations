# presentations

Public HTML reports that accompany Andrew Bowerman's posters and talks. Published with GitHub Pages at https://afb206.github.io/presentations/

| Folder | What |
|---|---|
| `aasc2026-growth-curves/` | Companion report to the AASC2026 poster "Sharp, honest or robust? What growth-curve models trade off when plant data are sparse" |

Each folder is self-contained (plain HTML, figures, sources with md5s). Folder names are part of printed QR addresses, so they are never renamed once a poster is printed.
